# Boundary Contract

## Author-fixed content

- 同一雨夜、同一饭桌直接承接 `CH_0008`；全章位于 `LOC_0008`，结尾只提出星港邀请。
- 保留合成套餐、过滤器、种地与无人农机笑话的功能，但按 `D005=A` 压成短回扣。
- 建立联邦核心殖民地与边缘世界差距、诺瓦尔的输出位置和隐性歧视。
- 学院事故严格采用 `D001=A`：解除训练机限速、验证手动下降、无人靶机规避、导航阵列受损、空域封锁、无人伤亡、险些取消学籍。
- 使用接近“屋里充满了快活的空气”的明显叙述致敬；只属作者层互文。
- 多家公司推进遗迹项目是可观察趋势；死亡增加只属克里斯听闻。
- 收束于童年梦想回忆及克里斯邀请何筠日后去附近星港看穿梭机。

## must_happen interpretation

- “继续谈怀才不遇”解释为从已建立的个人遭遇向结构性区域差距推进，不复述上一章的技术考核和署名案例。
- “仿佛一直飘在空中的心落地”通过身体松弛、开始参与旧事争辩、接受明日/稍后仍有生活安排表现；不直接宣告身份焦虑消失。
- “遗迹事务部核心部门”保留公共事实；何筠须纠正自身状态：部门是核心，他本人连正式外围编制都不是，只持候选/临时权限。
- 伤亡传闻被毛晓制止后，克里斯可以说明消息来源有限，不能以继续强调的方式绕过她的情绪边界。

## must_not_happen / forbidden additions

- 不复演 `CH_0008` 的合成餐长对话、故障诊断、资历审查三条件、报告附件署名、异常构件或有限分享约定。
- 不提墓灯、残留航道、舰队目的地、复苏、克隆、身份异常、记忆空白、EIDOLON-2 或完整任务风险。
- 不建立遗迹伤亡统计、死亡率、具体公司名单、项目数量、遗迹来源比例或公司间关系。
- 不补学院名、年份、训练机型号、损失金额、处分条款、同学身份或事故隐藏动机。
- 不使星港邀请在本章转化为实际移动，不建立新地点状态。
- 不让《孔乙己》致敬成为人物知识或世界内文化证据。

## POV and character-knowledge boundaries

- 第三人称限知 `CHR_0001`。
- 核心/边缘差距可由其个人经验、克里斯处境和有限叙述概括呈现；不得切入组织全知视角。
- 学院事故由何松讲述，何筠可出现主观熟悉、辩解或碎片反应，但不据此认证当前主体的客观连续性。
- 克里斯只掌握公开部门地位、身边报名个案、行业可见动向和未经证实的伤亡传闻。

## Reveal and secret boundaries

- `QUESTION_0001` 保持开放；家庭旧事和何筠的落地感不回答“他是不是原来的何筠”。
- 遗迹行业趋势不与何筠异常事故、墓灯或遗迹机制建立因果。
- 不载入或影射秘密 Canon。

## World / timeline / location hard constraints

- 旧主航道已崩裂；“靠近原主航道”是历史区位和遗留基础，不代表旧跨河系网络仍正常运作。
- 正文使用“联邦”，不建立“新联邦”为新政体名。
- 全章发生在晚宴续席的连续时间内；毛晓只添做小份热菜或处理厨房现有食材，不重新开启一顿完整晚饭。
- 何筠四十八小时后的预备评估、未签约状态和右腿轻微不适保持不变。

## Flexible expansion envelope

- 可补不建立长期事实的菜品操作、雨夜住宅变化、湿衣干燥、风与设施声、餐具和家务后果。
- 可补人物对宏观差距的个人化措辞、打断、改口、答非所问及短暂尴尬。
- 可补学院事故讲述中的家庭反应和何筠有限辩解，但不得越过固定事故事实。
- 可补童年问梦想时的可逆场景纹理，不为克里斯确定一个未获作者批准的终极梦想答案。

## Facts requiring author approval

- 正式写回时需批准：核心/边缘殖民地差距；学院事故；多家公司推进遗迹项目趋势；克里斯持有死亡增加传闻；童年梦想对话和星港邀请。

# Expansion Proposal

## Suggested scene sequence

1. **短回扣与添菜（约 500–700 字）**：毛晓见两人聊得开心，顺手添做小份热菜；“轨道局不给饭吃”引出过滤器与无人农机笑话，迅速结束合成餐话题。
2. **从个人处境到区域差距（约 900–1100 字）**：何筠观察克里斯的疲态；对话从工作机会自然扩大到核心殖民地、主航道遗留优势、巨企总部与诺瓦尔的输出位置，用个人经验承载隐性歧视。
3. **学院事故与家庭笑场（约 1100–1400 字）**：何松以“前途无量”拆台，逐层揭出限速解除事故；何筠辩解、克里斯追问、毛晓补刀。以明显《孔乙己》致敬作为笑场顶点。
4. **落地感（约 400–600 字）**：不单独抒情总结；让何筠在争辩、夹菜、记起家人反应和接受明日仍有安排的过程中松弛下来。
5. **遗迹行业伏笔（约 1000–1200 字）**：克里斯认真确认部门地位，何筠划清候选边界；报名个案、行业扩张和伤亡传闻依次出现。毛晓制止后，话题不继续渲染死亡。
6. **梦想与邀请（约 500–700 字）**：何筠想起小时候问梦想，克里斯当时不正面回答；当前克里斯提出改天去附近星港看穿梭机，本章停在邀请与何筠反应。

## Transitions and action microbeats

- 用毛晓添菜的实际动作启动，而不是重新说明所有人仍在饭桌。
- 从克里斯吃得快转到轮班/食堂，再从轮班疲态转向机会分配；每次转题都有上一句或可见状态触发。
- 学院事故由何松对“前途”的反讽引出，不突然插入背景资料。
- 遗迹话题由笑声消退后的认真提问进入；毛晓的制止改变克里斯的说法和音量，而非制造固定“房间安静”节拍。

## Sensory / spatial detail opportunities

- 热锅重新起声、厨房蒸汽改变窗面、湿工装逐渐不再滴水、雨风碰到藤架或屋檐、轨道辅助光在云层中的间接变化。
- 细节随人物状态选择：何筠先注意克里斯的疲态，松弛后才开始注意菜味、家务和父亲说话前的小动作。
- 不重复聚焦酒杯、手部伤口、机油或灯光；再次出现只在动作或状态发生变化时使用。

## Dialogue and emotional-subtext options

- 毛晓的问句表面责怪轨道局，实际是心疼克里斯；不需要旁白再解释一遍。
- 克里斯谈区域差距时仍能开玩笑，但在“需要他修、不给他资格”处减少机灵表达。
- 何松讲事故时慢慢加码，何筠试图控制损失，克里斯主动追问，使笑点来自关系与信息不对称。
- 遗迹伤亡出现后，毛晓的制止指向对何筠风险的担忧；克里斯举手认错并收住渲染，不继续用笑话消解。

## Pacing and information distribution

- 常规目标 `4000–6000` 可见字符；先完整生成六段功能，再测量长度。
- 核心/边缘设定拆入两到三轮带个人立场的对话与有限叙述，不集中成一段百科说明。
- 学院事故为本章喜剧峰值；遗迹伤亡是温度下降点；结尾用童年邀请恢复亲密但不消除伏笔。

## Situated Narrative Plan

- fixed narrative information / reversible scene texture / durable-state boundary: 固定层为区域差距、学院事故、行业扩张、传闻层级和邀请；雨声、添菜、器具与童年现场纹理可逆；任何新组织规则、项目统计或克里斯未来职位均属未授权长期状态。
- scene purpose, conflict, and end-state change: 何筠从被动接受家庭照料转为参与旧事与未来小约定；克里斯的兴趣由个人机械问题扩展到行业变化，但仍未获得入口。
- character state snapshot and relationship register: 何筠谨慎后松弛；克里斯疲惫、先玩笑后认真；毛晓照料但对死亡话题敏感；何松以克制慢节奏表达接纳并拆台。
- environment continuity through spatial relations and indirect cues: 厨房与饭桌之间的人物往返、雨风持续、食物温度和湿衣变化共同维持场景。
- representative object mentions and new function on reuse: 若再次写酒杯、手伤、工装或窗，只能承担喝完、疼痛反应、干燥变化或天气影响等新功能。
- lateral / indirect description opportunities: 用克里斯对工作机会的措辞、毛晓添菜、何松掌握旧事细节、何筠开始争辩表现关系和环境，不直接总结“他们像家人”。
- cinematic shot-list risks and compression plan: 合并取菜、落座、夹菜等低价值连续动作；不使用镜头推拉或逐动作短句。
- dialogue-ladder risks and paragraph-rhythm plan: 每组对话设置不同长度与叙述介入；宏观信息后必须有具体反应或行动后果，不连续十余轮一句一段。

## Prose Naturalization Plan

- meaning / fact / logic / information invariants: 保留作者六项决定、信息层级、未签约状态、同一地点与墓灯禁区；不减少核心/边缘设定或遗迹伏笔。
- locked style profile application: 日常轻松来自家人添菜、旧友拆台和事故旧闻；不把结构性歧视与伤亡传闻写成持续笑料。
- everyday-light baseline and serious-scene weight: 前半轻松，中后段降温，结尾回到亲近但保留外部风险。
- functional environment-detail plan: 每个环境细节至少承担时间推进、动作条件、人物观察或情绪转折之一。
- layered dialogue-detail plan: 让提问、回避、纠正、抢话和收声对应人物目的；不把世界设定写成问答教材。
- sentence and paragraph distribution: 家庭笑场可加快，宏观差距用较完整句群，遗迹传闻处收紧，结尾恢复舒展。
- over-summary to replace with scene evidence: “心落地”“隐性歧视”“怀才不遇”分别用参与争辩、资格措辞差异和工作/机会落差表现。
- character-specific voice and real-life texture: 克里斯口语直接且技术背景明显；何松慢、准、少说；毛晓以事务和制止表达关心；何筠以有限自嘲和辩解参与。
- character range across goal / pressure / relationship / physical state: 不让克里斯全程玩笑，不让毛晓全程担忧，不让何松只做金句输出，不让何筠每次压力都吐槽。
- repeated-trait performance to avoid: 避免连续“扯嘴角”、冷笑、举手投降、沉默、低头喝酒和拍肩膀；克里斯在 CH_0008 已有“举手投降”，本章优先换成收声或改口。
- recent-template / object / closing-line avoidance: 不复用“饭桌重新热起来”作为结尾，不以雨声单独收章，不重复手伤/机油证明疲劳。
- meme / slang permission and world-register boundary: 《孔乙己》明显致敬由作者批准，只出现一次且属于叙述层；其余梗来自人物关系和世界内处境。
