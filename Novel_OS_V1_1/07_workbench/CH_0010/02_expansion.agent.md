# Boundary Contract

## Author-fixed content

- 章节名《梦》；直接承接 `CH_0009` 同一雨夜。
- 克里斯告辞，何筠目送后回屋；保留“路上别掉沟里 / 滚”的旧友语气。
- 父母仍在做收尾家务和看地方新闻，三人谈裁员、停产、修理铺与卖烤鱼老人去世等琐事。
- 新旧毛巾的迟疑必须发生，并服务于身份疏离而非机制说明。
- 何筠在旧房间入睡，经历由旧港、失真广播、下沉、巨大井状结构、银白光流与毛晓呼名构成的回声井认知梦。
- 作者级回声井与克隆飞行员机制保持隐藏；本章不产生客观解释。
- 不存在克苏鲁式实体；原稿“庞大存在睁眼/井底东西上浮”的功能改由非人格化结构响应承担。

## must_happen interpretation

- “主角和克里斯聊了很久”解释为本章开场前后的余谈已经持续一段时间，正文只保留收束片段，避免重复 `CH_0008–0009` 的完整饭桌谈话。
- 地方琐事通过新闻播报、父母互相纠正和何筠追问交错呈现；不一次性列出四条信息。
- 旧毛巾是一次明确选择：先展示新旧并存，再让记忆与陌生感冲突，最终拿起旧毛巾；离开卫生间后不继续反复点名。
- 梦中“认出回声井”只表示何筠给巨大井状意象贴上自己已知的公司术语，不表示梦准确呈现真实设施。
- 光流中可有难以辨认的人形、地点和舰船碎片，但叙述不得说它们是记忆、人格、记录或真实历史。
- 未知感来自规则缺失：声音没有明确方向、动作缺少反馈、尺度无法判断、时间顺序不可靠、结构对感知产生响应。

## must_not_happen / forbidden additions

- 不载入、改写或解释作者专用机制材料的具体内容。
- 不使用“信息本身正在震动”“全部构成信息”“被保存的人格”等接近作者答案的判断句。
- 不把梦认证成预言、通讯、回声井远程连接或真实过去。
- 不出现具体呼唤者、井底生命、神意、宇宙意志或超自然捕食者。
- 不把黑色立方体项目图标称作现实中的回声井机器。
- 不因轨道局裁员和工业线停产补精确人数、企业名称、政策、月份、经济数据或与遗迹行业的因果。
- 不新增克里斯长期烟瘾、毛晓/何松知晓秘密、何筠入职或评估提前。

## POV and character-knowledge boundaries

- 第三人称限知 `CHR_0001`。
- 前半只允许何筠观察父母、新闻与旧物；后半只允许其梦中感知和联想。
- “回声井”命名来自既有 `L4` 知识；梦境新增内容只能标为主观体验。
- 毛晓在结尾呼名的现实来源取决于 `D003`；在决定前不写她已进入房间或知道何筠做梦。

## Reveal and secret boundaries

- `QUESTION_0001` 与 `QUESTION_0003` 均保持 `OPEN`。
- 梦可把 `QUESTION_0003` 从抽象技术疑问转成主观意象，但不得提升秘密 reveal status。
- 作者级新增机制只进入后续秘密 Delta 候选，不进入普通世界卡、人物知识或读者知识。

## World / timeline / location hard constraints

- 现实场景只在 `LOC_0008` 与门前；不建立或抵达星港。
- 克里斯次日早班与接近深夜状态要求门前告别尽快结束。
- 梦中旧港不是现实地点更新，不创建地点 ID。
- 新闻与闲谈中的地方变化若进入正文，只建立有限当前事实，不建立完整经济危机。

## Flexible expansion envelope

- 可补父母对新闻的熟人式反应、家务顺序、住宅夜间声响和何筠偶尔插话。
- 可将“太阳晒过”的味道写成先前晾晒后保留的干燥气息，不与当夜雨水冲突。
- 可用连续段落整合洗漱、关灯和入睡，不做动作清单。
- 可重构梦境空间，使旧港到井状结构的转换有感知逻辑而非镜头切换。

## Facts requiring author approval

- 正文完成后：轨道局裁员、两条生产线停产、卖烤鱼老人去世、克里斯本次吸烟动作、梦境主观证据及章节事件。

# Author-input Logic and Information-gap Review

## Causality / motivation gaps

- `BLOCKER / D002`：快速入睡“像有人拉了一把”与后续呼唤容易被读者理解为外部接触；作者尚未确认这是纯梦、机制作用还是保留歧义。
- `HIGH / D004`：原稿先禁止机制泄露，又断言光流中全是人、人格和记忆，要求互相冲突。
- `HIGH`：原稿使用“庞大存在睁眼”“井底东西上浮”，与明确禁止克苏鲁式实体冲突；按禁止项直接删除实体化解释，不需额外选择。

## Timeline / location / capability gaps

- `HIGH / D001`：“很多年没睡过真正意义上的床”缺少既有服役与民用航行支持；若取字面，会新增极端生活史。
- `PASS`：克里斯在同一雨夜离开、何筠回屋、洗漱并睡眠，地点和时间连续。
- `PASS`：梦中旧港和井状空间不计现实移动。

## Knowledge / reveal gaps

- `BLOCKER / D002`：必须确定梦是否只有主观证据层，否则可能改变 `QUESTION_0003` 揭示状态。
- `HIGH / D004`：必须确定允许出现模糊人形，还是完全限制为非人物画面；两种选择都会维持机制隐藏，但线索强度不同。
- `PASS`：何筠可从已知公司术语把梦中结构称为“回声井”，但不能知道其设计与功能。

## Mutually incompatible requirements

- 已自动解决：非克苏鲁要求高于原稿实体化比喻，改为结构、尺度和感知异常。
- 待作者解决：作者级机制保持隐藏，与“光里全是被记录的人”的直述不能同时成立。

## Bounded reversible assumptions

- 新旧毛巾均由毛晓当日或此前整理；不建立特殊材质或技术。
- 地方新闻主持人和卖烤鱼老人保持未命名，不建立长期角色卡。
- 梦中旧港只借用童年环境形状，不认证真实地点、时间或记忆来源。

# Expansion Proposal

## Suggested scene sequence

1. **门前告别（约 350–500 字）**：雨后风、烟头熄灭、早班与损友对话；何筠目送后回屋。
2. **夜间家庭余谈（约 800–1000 字）**：新闻终端与收尾家务交织地方琐事，父母互相补充或纠正；从“宇宙”回到具体小城。
3. **洗漱与旧物迟疑（约 700–900 字）**：新旧毛巾选择、有限记忆、母亲门外询问；旧物不认证身份。
4. **旧房间与入睡（约 500–700 字）**：房间空间、远处运输声、身体疲惫；按 `D001–D002` 控制措辞和因果。
5. **旧港失真（约 900–1200 字）**：无风、无声、无倒影、广播失真、黑暗下沉；避免短句阶梯。
6. **井状空间（约 1200–1600 字）**：尺度错位、结构与光流、模糊影像、非方向性响应；以毛晓呼名收束或进入短醒转，取决于 `D003`。

预计正文约 `4450–5900` 字符；初次扩写先完整覆盖场景，之后再执行长度门。

# Dialogue and Style Plan

- 前半人物对话保持长短不齐：毛晓以家务和催睡推进，何松以新闻和经验式评论接话，何筠不承担连续吐槽功能。
- 梦境减少引号和拟人化“呼唤”，更多使用无法确认来源的声压、节律与身体反应；“呼唤”只保留为何筠的主观命名。
- 不反复使用“忽然、开始、慢慢、越来越、安静、几秒”；通过句法变化和实际状态变化推进。
- 不复制 `CH_0009` 的饭桌热闹或“落地感”总结；本章从日常收束转向身份错位和未知梦境。

# Proposed Decision Matrix

## D001 — “真正的床”

- `A（推荐）`：改为“很多年没睡过自己的床/这张床”；保留返家触感，不新增极端生涯事实。
- `B`：保留字面上的多年未睡正规床；作者需确认其服役和退役后长期住宿条件确实如此。

## D002 — 梦境客观状态

- `A（推荐）`：保持完全未证实。异常入睡、呼唤和井状意象都是何筠主观体验，既可被解释为疲劳与既有信息重组，也不排除未来其他解释。
- `B`：作者确认存在客观外部触发，但本章不揭示触发者或机制；这会成为秘密 Canon 新事实并改变因果层。

## D003 — 章节结束位置

- `A（推荐）`：停在毛晓隔着多层梦呼唤“何筠”，不写醒来。
- `B`：何筠在本章醒来，用短暂现实反应确认母亲确实在叫他，但不解释梦。

## D004 — 人形线索强度

- `A（推荐）`：光流只闪过无法辨认的人形、地点和舰船切片；何筠不能判断其性质。
- `B`：允许何筠主观联想到“像记忆或人的残影”，但立即保留不确定性；不得使用“全是被记录的人”等认证句。

## Prose Naturalization Plan

- meaning lock：保留告别、家庭夜谈、旧毛巾迟疑、旧房间入睡、旧港失真、井状空间和母亲呼名的顺序与信息量；不以自然化为由删减场景。
- syntax distribution：前半以中等长度生活段落为主，梦境阶段逐渐拉长感知句并穿插少量短句，不连续使用同构断句制造神秘。
- summary control：地方经济只在人物谈话与新闻反应中出现；梦境不在画面后附机制总结。
- character voice：克里斯的最后一句保持损友语气；毛晓以收拾和催睡表达关心；何松只在具体生活话题中开玩笑；何筠进入梦前逐渐少说话。
- environment integration：雨后风、厨房收尾、新闻声音、旧物选择、房间远声与梦中反馈分别承担时间、关系或认知功能，不反复点名单一物件。
- continuity and anti-film：用门内外、卫生间到卧室、旧港到井状空间的感知因果维持转场；不使用镜头、特写、切换或逐动作清单。
- meme/register：本章不主动加入网络梗；“路上别掉沟里 / 滚”已经足够维持朋友语域，梦境完全退出玩笑语气。
