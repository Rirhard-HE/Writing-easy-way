# Objective Ontology — Information Is Reality

## Author-confirmed core

**信息即现实。**

这里的“信息”不是普通意义上的数据、文字、信号或观察结果，而是**定义一个事件/对象/状态所需要的全部构成信息的集合**。

一个事件的现实性，不依赖某一个特定观察者是否亲眼看到它。

例如：

- 观察者 A 位于中国；
- 事件 E 发生在美国；
- A 无法直接观察 E；
- 但 E 的其他观察者、记录系统、物理痕迹、通讯、转述以及后续因果结果，可以把关于 E 的构成信息传递给 A；
- 当 A 获得足够的相关信息时，A 可以认知 E；
- 因此，“未被某个观察者直接观察”不等于“事件不存在”。

## Event Information Set

对任一现实事件 `E`，存在一个定义它的构成信息集合：

`I(E) = {i1, i2, i3, ... in}`

其中可以包括但不限于：

- 发生主体；
- 时间；
- 空间位置；
- 状态变化；
- 参与对象；
- 前因；
- 结果；
- 物理痕迹；
- 观察结果；
- 记录；
- 记忆；
- 对其他事件造成的影响；
- 其他能够约束并共同定义该事件的因素。

**单条信息不是现实。现实是构成信息达到足够规模、完整度与相互约束后形成的集合。**

## Reality Threshold

一个潜在事件的信息集合达到某一“现实阈值”后，该事件取得稳定现实性。

目前作者已确认的原则：

1. 构成信息必须达到足够数量级；
2. 多个构成因素共同形成集合；
3. 该集合能够被不同观察者通过不同路径获得或推导；
4. 该事件能够进一步影响其他事件；
5. 当上述条件达到足够程度，该事件成为所有观察者可以原则上认知的现实。

因此，现实不是由单一观察行为创造，而是由**信息集合的形成、稳定和因果嵌入**产生。

## Observer Rule

观察者不是现实的创造者，而是现实信息的：

- 接收者；
- 携带者；
- 转述者；
- 记录者；
- 新因果链的参与者。

观察本身会产生新的信息载体，因此一个事件被更多观察者、设备、制度与后续事件记录后，它的信息集合会更加广泛地嵌入现实。

这意味着“观察”可以增强事件的可认知性与信息扩散，但不应简单理解为“只有被观察才存在”。

## Causal Embedding

事件一旦影响其他事件，其后果本身也成为定义原事件的信息来源。

例如：

`E0 -> E1 -> E2 -> E3`

即使 E0 的原始记录部分丢失，只要 E1/E2/E3 中仍然保留由 E0 引起的结构性结果，E0 的信息仍然部分存在于现实中。

因此，已经深度嵌入因果网络的事件，比孤立事件更难被完整擦除。

> Working concept (not yet formally named by author): reality inertia / causal anchoring.

此概念目前作为推导模型使用，在作者正式命名前不得作为正文术语直接出现。

## Important distinction: information != belief

当前模型默认：

- 传闻、谣言、主观相信本身只是信息载体的一部分；
- 单纯“很多人相信”并不足以自动生成现实；
- 一个稳定现实需要能够形成足够完整并相互约束的事件信息集合，并能够进入现实的因果网络。

**是否存在“人为构造足够完整的信息集合，从而令原本不存在的事件现实化”的技术或现象，尚未由作者最终确认。**

这一问题必须保留为 OPEN_CANON，禁止 Agent 自行决定。

## Identity and continuity

人物、意识、人格也可以被视为事件/状态的连续信息集合。

因此人物连续性问题可以抽象为：

- `CONTINUOUS`：前后状态的信息集合能够建立稳定连续关系；
- `MISSING`：连续链中存在无法补足的信息缺口；
- `DUPLICATE`：同一身份信息链出现两个或更多具有有效连续依据的分支；
- `CONFLICT`：不同信息集合同时对同一身份/事件提出互斥定义。

### Author-approved branching continuity rule

作者已通过 `GENESIS_DECISION_001 / AD-004-C` 确认以下隐藏工作规则：

1. 有效身份连续性同时需要**因果传递**与**足够的身份信息**；仅有表面相似或独立复制不足以自动确认连续性。
2. 一次有效传递可以形成两个或更多有效分支；多个分支可以同时具有连续依据。
3. 多个有效分支并存时标记为 `DUPLICATE`，但该标记本身不裁定哪个分支是“原版”。
4. 连续链存在无法补足的信息缺口时标记为 `MISSING`。
5. 多个信息集合对同一身份提出互斥定义时标记为 `CONFLICT`。
6. 法律身份、机构说法和角色自我认知属于 L2-L4 模型，不能自动覆盖 L0 判定。

“足够的身份信息”与“有效因果传递”的精确阈值仍为 `OPEN_CANON`。何筠的最终 L0 身份也继续保持 `OPEN_CANON`；迁移中应将其记录为一个叙事身份及多个可能的状态/实例，不得预判最终答案。

## Reality erasure — author-approved hidden working model

“擦除”不能简单等同于物理摧毁。

作者已通过 `GENESIS_DECISION_001 / AD-003-A` 确认采用**图谱式定向擦除**作为 L0 隐藏工作模型。

若某种能力真正针对事件的信息集合，它理论上可能作用于：

- 对象本身；
- 对象当前状态；
- 直接物理痕迹；
- 记录；
- 观察者记忆；
- 事件产生的部分因果后果；
- 事件与其他事件之间的关联。

事件的信息载体、复制版本、记录、记忆、痕迹与因果后果构成相关图谱。擦除作用于被指定和覆盖的节点及关联；未被覆盖的远端记录、记忆、复制品或因果后果可以继续残留。

但**擦除必须处理事件已经分布到多少独立信息载体和因果链中**。绝对删除在原则上可能，前提是穷尽与该事件相关的全部有效图谱。任何具体事件是否真正完成这种穷尽，必须保持为事件级 `UNRESOLVED`，除非作者另行确认。

因此，越是被大量独立观察、记录并产生广泛后果的事件，理论上越难彻底从现实中消除。

具体能力能够覆盖的范围、成本、传播方式、追溯深度、失败形态与实际极限仍为 `OPEN_CANON`。

## Echo Well compatibility

### Author-confirmed mechanism

- “回声井”在客观层指围绕信息凝结点建造的一系列设施与装置，并非单一机器。
- 旧联邦先发现一个具有类似回溯效果的特殊区域，再围绕该区域发展相关工程阵列。
- 阵列能够保存被记录实体在某一选定时间点的全部构成信息。
- 克隆飞行员技术结合实时脑电波记忆记录、对基因克隆体大脑皮层的短期精准刺激，以及回声井保存的刻录时刻过往状态信息，以在克隆体中形成人格与记忆。
- 刺激精准度与记录畸变会产生副作用；具体阈值、范围、设施几何、实现细节和个案因果仍未确定。

以上内容仅属 `L0_OBJECTIVE_TRUTH / AUTHOR_ONLY / HIDDEN`。它不回答何筠当前主体的最终连续性，也不认证 `CH_0010` 梦境是真实记忆、通讯、预言或设施活动；不得进入普通上下文包、人物知识或读者确认状态。

现有正文中的“回声井”与本体论高度兼容：

- `保存` 可以理解为保存事件/人格/文明的信息集合；
- `校验` 可以理解为检查信息集合的一致性、缺失、冲突或重复；
- `连续性维护` 可以理解为维持一个事件/人格跨状态变化后的有效连续链；
- `人格回声` 可以理解为人格信息集合的可恢复/可验证结构；
- `存在重复` / `存在缺失` 可以理解为连续性校验结果，而非普通软件报错。

这些是目前允许的作者侧解释框架；正文中的现代人物不应自动掌握这一层真相。

## Knowledge layers

同一个现象必须区分：

- `L0_OBJECTIVE_TRUTH`：作者确认的现实本体规则；
- `L1_OLD_FEDERATION_MODEL`：旧联邦对底层规律的理解；
- `L2_MODERN_FEDERATION_MODEL`：现代联邦可验证的工程理论；
- `L3_ORGANIZATION_MODEL`：科隆诺、遗迹事务部、军方等机构掌握的信息；
- `L4_CHARACTER_KNOWLEDGE`：具体角色认知；
- `L5_READER_KNOWLEDGE`：读者已经获知的真相层级。

任何 L1-L4 的陈述都可以是不完整、近似甚至错误的，不能自动覆盖 L0。

## Open canon questions

以下问题尚未由作者最终确认，Agent 不得自行补完：

- 构成信息达到现实阈值时，“数量级 / 完整度 / 一致性”分别如何计算？
- 是否存在现实强度或现实稳定度的连续量，而非单一存在/不存在二值？
- 一个从未发生的事件，能否通过人工构造足够完整的信息集合被现实化？
- 互相矛盾但都达到阈值的两个信息集合会发生什么？
- 两个现实版本能否并存？
- 现实是否会主动选择一致性更高的版本？
- 绝对删除是否曾在某个具体事件中真正实现？
- 何种能力、成本或条件能够穷尽一个事件的全部有效图谱？
- 擦除必须追溯到多深的因果链才能使一个事件彻底失去现实性？
- “足够的身份信息”与“有效因果传递”的精确阈值是什么？
- 观察者本身是否必须具备意识，还是传感器/数据库/物理痕迹也可作为信息载体？
- “信息集合”是否存在最小不可约构成单位？
- 时间是否只是信息集合之间的有序关系？
- 空间是否也是事件信息关系的一种表现？
- 大崩溃是否与现实信息层失稳直接相关？
- 回声井是在现实层上运行，还是它本身就是现实层的一部分？
