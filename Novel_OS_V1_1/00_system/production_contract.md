# Production Contract

## 角色分工

### 作者负责

- 每章核心内容与剧情所有权；
- 关键事件、角色选择、谜底与情感落点；
- 新增/修改设定及 Retcon；
- 最终正文与长期状态批准。

### Agent 负责

- 从权威状态和相关原稿证据构建最小上下文；
- 把作者输入整理成可执行边界合同；
- 在 `flexible` 范围内补充连接、细节、节奏和表达；
- 检查人物、时间线、世界规则、知识边界、伏笔与揭示门；
- 对明显设定冲突给出影响提醒；
- 检查作者输入自身的因果、知识、时空与信息缺口，并在重大缺口处暂停索取信息；
- 按 `prose_fidelity_v1` 保留语义和信息层级，同时降低模板化表达；
- 按锁定档案 `daily_light_detailed_v1` 保持日常轻松，并增强有功能的环境和对话细节；
- 每次生成自动执行 `situated_prose_v1`，用情境化人物、环境侧写和小说叙述组织正文；
- 提取待批准的章节 Delta。

## 生产正文准入条件

生成生产级章节正文前必须满足：

1. 作者核心材料非空，且 brief 标记为 `status: ready / author_input_complete: true`；
2. `must_happen` 与 `must_not_happen` 可执行且不互斥；
3. POV 或视角处理方式明确；
4. `BLOCKER` 和重大 `HIGH` 已由作者决定；
5. 边界合同没有把 Agent 提案伪装成作者事实；
6. 秘密揭示门已检查；
7. 正文扩写范围已由作者允许。
8. 已生成阶段记录的来源 SHA-256 与当前来源一致；作者输入变化后必须重新生成或标记 `stale`。
9. 自 `CH_0005` 起，草稿已通过终审前长度与去重门：`4000–6000` 字符直接通过，`6001–9000` 已取得作者保留决定或完成压缩，超过 `9000` 不得进入终审。
10. 草稿已清除无功能标的物重复、同构停顿句复用和缺席概念清单式解释。
11. 自 `CH_0009` 起，作者输入逻辑审查已为 `PASS / AUTHOR_RESOLVED`，未解决逻辑缺口为 0。
12. 自 `CH_0009` 起，终审中的原意/信息保持、AI 模板、风格一致性、人物情境范围、梗/语域和逻辑缺口均为 `PASS`。
13. 自 `CH_0009` 起，brief、扩写提案、草稿和终审均绑定 `daily_light_detailed_v1`；除非作者明确记录覆盖决定，不得换用其他基础风格。
14. 自 `CH_0009` 起，所有生成阶段均绑定 `situated_prose_v1`；环境连续性、电影分镜化、对话梯和总体叙事方法检查均为 `PASS`。

## 默认扩写原则

- 优先保留作者的事件顺序、人物意图、关键表达与情绪方向。
- 优先补“可见、可听、可执行”的场景内容，不用抽象解释替代戏剧行动。
- 不确定时收缩扩写范围并标记问题，不用新设定填洞。
- 作者文本与 Agent 新增内容在审批前都留在 workbench；最终批准后才进入 manuscript。
- 扩写后先测量长度并审查重复，再进行最终 prose review；不得先写终审结论、后补长度判断。
- 先完整生成已批准场景，再测量长度；不得用常规字数范围预先削减场景信息密度。
- 自然化改写要改变句法和节奏分布、减少过度概括并增加有功能的生活痕迹，但不得改变事实、因果、角色知识和信息量。
- 网络梗只在人物与情境允许时使用；现实中文互联网原句若造成时代错置或文化泄漏，必须改成世界内语域或不用。
- 环境细节必须承担空间、行动、因果、人物、情绪或伏笔功能；对话细节应增加有效轮次、潜台词与人物差异，不得写成设定问答或稀释严肃后果。
- 性格标签只表示长期倾向；具体反应必须结合人物当下目标、压力、疲劳、身体状态、关系与风险，既防止单一重复，也防止无依据变脸。
- 作者未逐次审阅时仍自动保持锁定规则与最近获批正文的一致性，但这不解除任何人工审批门。

## 完成定义

一章只有在正文、最终审查、Memory/Setting Delta 和人工批准全部完成后，才算生产完成。提交与推送仍需独立授权。
