# Chapter Transaction Workflow

```text
AUTHOR BRIEF
    ↓
CONTEXT PACK
    ↓
EXPANSION PROPOSAL
    ↓
PARALLEL CONTINUITY REVIEW
    ↓
AUTHOR DECISION
    ↓
DRAFT
    ↓
FINAL PROSE REVIEW
    ↓
MEMORY DELTA
    ↓
AUTHOR APPROVAL
    ↓
CANON / STATE COMMIT
```

## 关键规则

- “生成正文”与“写回状态”是两个不同动作。
- 一章结束后只提取 **Delta**，不重写整套设定。
- Review Agent 只读；主 Agent 负责汇总。
- BLOCKER/HIGH 未经作者明确处理，不进入 finalize。
