# 项目规则

## 基本信息

- 小说名：灰烬重生
- 类型：TBD
- 预计总字数：5,000,000–8,000,000
- 默认章节长度：由作者逐章决定；未指定时不得用固定字数替代剧情完整度
- 默认 POV：由作者逐章指定；未指定时保持作者素材的视角并报告歧义

## 作者绝对权限

以下内容只有作者可以最终确认：
- 主线/支线剧情方向
- 世界硬规则
- 角色死亡、复活、重大身份变化
- 未解谜团的真相
- Retcon
- 最终正文

作者可以增加、澄清、覆盖或 Retcon 既有设定。既有 Canon 与原稿证据不能阻止作者修改，但 Agent 必须在发现明显冲突时说明受影响范围，并保留被替代版本的来源与历史。

## 作者主笔原则

- 每章必须先有作者提供的核心内容：剧情材料、场景意图、关键行动/对话或明确剧情梗概。
- Agent 负责把作者内容整理成边界合同，并进行受约束的内容扩写。
- Agent 不得以“补充”为名接管主线、谜底、重大角色决定或世界硬规则。
- 作者未提供足够核心内容时，可以准备上下文和指出缺口，但不得自行生成生产级正文。
- 作者输入不被假定为天然无矛盾；Agent 必须检查因果、时间、地点、能力、知识与揭示边界。明显信息缺口会改变剧情、人物选择或长期状态时，必须向作者索取信息。
- 自 `CH_0009` 起，生产正文遵循 `00_system/prose_generation_policy.md`：自然化表达不得改变原意、事实关系、逻辑结构和有效信息量。
- 自 `CH_0009` 起，生产正文锁定 `00_system/prose_style_profile.md` / `daily_light_detailed_v1`：保留日常轻松的基准语感，增强有功能的环境细节和有层次的对话细节；严肃场景不得被强行喜剧化。
- 自 `CH_0009` 起，每次生成自动执行 `00_system/narrative_generation_directive.md` / `situated_prose_v1`。作者未逐次审阅时仍按锁定基线和最近获批正文保持一致，但不因此获得正文批准、Delta 或受控写回权限。
- 只有作者明确要求覆盖或解除锁定，并在章节工作流中记录决定后，才可更换基础风格。

## Agent 禁止行为

- 不得把建议自动升级为 Canon。
- 不得为了消除矛盾而私自改旧设定。
- 不得让角色获得其 `knowledge.md` 中不存在的信息。
- 不得提前揭露被锁定的伏笔/谜团。
- 不得直接修改受控目录，除非存在明确人工批准。
- 不得把作者的讨论性想法误判为正式设定变更。
- 不得因新设定与旧设定冲突而擅自拒绝作者修改；应先提醒影响，再按明确决定执行。
- 不得把“降低 AI 感”理解为删减难写信息、故意制造错字病句、统一添加口头禅或强行插入网络梗。
- 不得把“增强细节”写成环境陈列清单、设定问答或无功能的对话轮次，也不得借细节新增未经批准的事实。
- 不得把角色卡中的显著性格当作全天候输出模板；人物反应必须同时服从当下目标、压力、关系、身体状态和现场风险。
- 不得依赖反复点名一个物件维持环境，不得把小说写成摄影分镜、逐动作短句清单或整章等宽对话梯。
