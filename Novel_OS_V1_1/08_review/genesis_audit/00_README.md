# Genesis Audit — 灰烬重生初稿

Status: `PASS_1 / NOT_CANON`

Purpose: reverse-engineer the existing ~120k-character draft into Novel OS without silently freezing draft-era assumptions into canon.

## Rules

1. Nothing in this folder is canonical merely because it was extracted from prose.
2. Dialogue, scientific explanations, corporate documents, AI statements, and POV interpretation are evidence of **belief/knowledge**, not necessarily objective truth.
3. Author-supplied hidden facts outrank draft-era theories but must remain reveal-gated.
4. Retcon candidates should be changed only after impact analysis identifies affected scenes.
5. Stable IDs should be assigned when the author approves an entity/card, not solely because a name appears in the draft.

## Pass 1 scope

- Core ontology / mystery interface
- Civilization history and politics
- Major technology stack
- Major locations / organizations
- Main cast and expedition cast
- Continuity and reveal risks
- Structural anomalies in the draft document

Later passes should add exhaustive scene/event/timeline extraction and per-character knowledge states.
