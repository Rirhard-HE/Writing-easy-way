# Reveal Guard — Pass 2

## Active gate

`CANON_SECRET_ONTOLOGY_001` 继续为 `AUTHOR_SECRET / L0_OBJECTIVE_TRUTH / HIDDEN`，没有批准任何正式章节或场景作为最早揭示点。旧稿中接近真相的理论、梦境词语和异常效果不构成新生产线的揭示授权。

## Safe pre-reveal manifestations

- 保存、校验、连续性、重复、缺失、冲突等可观察标签或结果；
- 物体、记录、记忆或因果关系出现不完整、矛盾、擦除样残留；
- 人物或机构提出互相竞争、可能错误的理论；
- 何筠、回声井、雅典娜等出现无法由当前科学完整解释的异常；
- 由作者 brief 明确要求的有限线索，且旁白不认证其机制。

## Forbidden agent exposition before gate opens

- 直接陈述秘密本体命题；
- 完整解释图谱式定向擦除、绝对删除条件或分支身份判定；
- 让现代联邦、角色或全知旁白凭 Agent 推导掌握 L0；
- 自动裁定何筠的最终身份、回声井本体/起源、灰烬号事故或大崩溃真因；
- 把普通信号、数据库记录、人格编码和本体层信息混成同一种机制；
- 因旧稿曾经暴露线索而默认新读者已经知道。

## Context sanitation

普通 `01_context.auto.md` 和 `02_expansion.agent.md` 只能接收本文件中的安全边界与可观察表现，不能复制秘密本体解释。连续性审查员如需查看秘密文件，只能报告最小化的 `REVEAL_CONFLICT` 和证据路径。

## Gate change rule

只有作者明确指定揭示内容、范围和最早章节/场景后，才能修改 `reveal_status` 或 `earliest_reveal`。批准某个现象出现，不等于批准机制解释；批准人物假说，也不等于批准旁白认证。
