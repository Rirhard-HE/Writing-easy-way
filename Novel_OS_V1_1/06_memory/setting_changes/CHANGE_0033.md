# Setting Change

## Previous fact

- `LOC_0005` 已建立殖民世界、气候、生态与边缘位置，但日长此前属于不得由 Agent 自行补写的空白。

## New fact

- 诺瓦尔完整自转周期按联邦标准时折算约 26 小时。
- 本地居民使用晨段、午段、昏段、夜段四段制。
- 四段不要求等长；晨段和夜段可相对较长，午段和昏段更多承担工作、通勤和生活分界。
- 港口、学校、企业排班等需要精确时间时仍可使用标准时。
- 四段制是社会生活惯例，不是新的物理时间单位。

## Boundary

- 不补精确天文秒数、季节长度、历法结构或四段固定小时数。
