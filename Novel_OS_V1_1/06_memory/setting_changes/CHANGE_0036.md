# Setting Change

## Previous fact

- 已知条件要约包含完成任务后免除全部债务与克隆费用、`FAC_0002` 候选资格、`SYS_0007` 使用权，以及可取消的教学评估与有限舰队资料。

## New fact

- 未接受的远航条件要约还包括债务暂停计息。
- 任务所需舰船、设备与训练资源由项目体系提供，而非要求何筠个人购买。
- 何筠在家庭对话中把潜在职责描述为任务区航行和现场处置层面的“战术指挥”。

## Boundary

- 上述条款尚未生效；何筠仍未正式接受、签约、入职、开始训练或获得任命。
- 不建立暂停计息的精确生效日、利率、违约恢复方式或完整法律效力。
- 不把“项目资源”写成何筠个人产权，也不固定完整舰队数量和人员编制。
