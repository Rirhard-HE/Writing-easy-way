# Setting Change

## Exact author decision

- 新增联邦核心殖民地与边缘世界差距：核心区靠近原主航道、自动工业更密集并聚集许多巨企总部；诺瓦尔等边缘世界更多提供原料、人口、士兵、飞行员和债务人，并存在隐性歧视。

## Previous fact

- 生产状态已建立殖民地专门化、巨企实际权力和克里斯的资历门槛，但没有完整建立当前联邦内部的核心—边缘发展结构。

## New fact

- `SYS_0012` 描述联邦内部的广泛区域结构：核心地区聚集产业、总部、资格和机会，边缘世界更多输出资源与被招募人口。
- 核心地区履历可能获得更高认可，边缘经验会遭遇不写入公开规则的间接歧视。
- `LOC_0005` 属于该结构中的边缘世界；克里斯的外派经历提供一个人物层实例。

## Conflict reminder delivered

- 该结构不构成正式法律等级、完整经济制度、精确统计或所有殖民地的绝对规则。
- 旧主航道邻近性不表示跨河系网络恢复；差距的唯一历史成因和变化速度均未建立。

## Impact and synchronized files

- 新建 `SYS_0012`，更新 `FAC_0005`、`LOC_0005`、`FAC_0008`、相关人物状态及章节/事件 Memory。
