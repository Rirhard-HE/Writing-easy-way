# Setting Change

## Exact author decision

- 近年多家公司推进遗迹项目属于可观察行业趋势；“相关项目死亡人数增加”仅是克里斯听到的未经证实传闻，不建立客观统计。

## Previous fact

- 生产状态已建立个别遗迹组织和克里斯的兴趣；`CH_0008` 没有采用遗迹死亡率传闻，也未建立多家公司共同增加项目活动的趋势。

## New fact

- 公开招聘与项目公告显示，近年许多公司增加遗迹相关开发、适配或合作活动。
- 项目可能来自企业自行发现的遗迹，也可能使用从别处取得的遗迹设备、残件或产品；实际来源网络未知。
- 克里斯听过死亡增加的说法，但没有正式统计，保持未证实传闻层。
- `QUESTION_0008` 追踪行业扩张的原因和来源变化。

## Conflict reminder delivered

- 不建立客观死亡增长、死亡率、项目数量、完整公司名单、来源网络或与 `LOC_0002` 的因果。
- 不让克里斯因此获得遗迹资格、内部消息源或未来舰队职位。

## Impact and synchronized files

- 新建 `QUESTION_0008`，更新相关人物知识、章节卡和 `EVT_000010`。
