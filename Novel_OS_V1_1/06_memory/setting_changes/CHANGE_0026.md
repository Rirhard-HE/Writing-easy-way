# Setting Change

## Exact author decision

- 新增克里斯的轨道维护工作、可观察机械才能、职业受限状态与遗迹科技兴趣。

## Previous fact

- 生产状态已建立诺瓦尔依赖轨道射灯辅助气候，但未建立西陆第四行政区轨道维护局、克里斯的工作或职业处境。

## New fact

- 克里斯受雇于 `FAC_0008`，参与维护诺瓦尔行政区对应的老旧轨道设施。
- 他曾识别西部轨道射灯阵列牵引架导向总线的间歇性微裂，并设计测量方法定位故障。
- 他通过技术考核但未通过资历审查；在实际工作中受到依赖，正式署名和晋升认可有限。
- 他希望理解旧设备和遗迹技术的控制载体、能源接口、材料结构与运行原理。

## Conflict reminder delivered

- 不认证克里斯为遗迹工程师，不建立未来舰队职位或高级遗迹能力。
- 单次维修与报告经历不扩展为 `FAC_0008` 的普遍制度。
- 异常旧构件只属于克里斯的个人陈述，其来源、性质和遗迹分类未确认。

## Impact and synchronized files

- 新建 `FAC_0008`，更新 `CHR_0005` 人物状态、`LOC_0005` 关联和章节/事件 Memory。
