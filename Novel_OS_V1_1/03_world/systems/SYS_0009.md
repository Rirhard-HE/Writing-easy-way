# System / Network

## Stable facts

- 大崩裂前，旧联邦人类拥有稳定的跨河系星门航道网络，至少连接银河系、仙女座与小麦哲伦云。
- 超距通信支持跨越河系的数据同步；复杂而便捷的网络推动了殖民地高度专门化。

## Current state

- `SYS_0005` 后跨河系主航道失效，仙女座与银河系及其他外部旧联邦区域失联。

## Unresolved

- 完整覆盖范围、节点数量、拓扑、工程机制及每一条支线的状态均未建立。

## Reveal constraints

- 不得从跨河系主航道失效推导仙女座内部每一座星门都同时永久停运。

- 无。
